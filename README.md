# NASA Space Apps Challenge 2026

Workspace at `/Volumes/Dev/nasa-space-apps-2026` (`https://www.spaceappschallenge.org/2026/`).

## Projects

1. [TerraSpan Earth Twin (`projects/project_1`)](projects/project_1/PROJECT.md): Keyless NASA orbital fire, meteorology, IEEE 738 ampacity derate, and space weather telemetry workstation built with React, TypeScript, Tailwind CSS, ObsidianUI (`ParallaxSlider`, `StatusBars`, `SplitShowcase`, `DiscoverButton`, `InteractiveHoverButton`, `FlipText`), AI Canvas (`WireframeGlobe`, `GlassDock`, `SourceRail`), and custom editorial halftone plates (`public/nasa-gallery/`).
2. [CradleFlow Junior Astronaut Mission Trainer (`projects/project_2`)](projects/project_2/README.md): React Flow outpost automation canvas and Shackleton Ridge / Jezero Crater radiation survival trainer linked to live NASA DONKI, NOAA SWPC GOES-18, and NASA OSDR radiobiology studies.
